## 🎯 Objetivo:

1. Praticar HTML, CSS, JavaScript e Figma em um projeto com foco comercial;
2. Desenvolver um site de apresentação de marca com produtos e serviços;
3. Criar layouts responsivos otimizados para diferentes dispositivos;
4. Aplicar conceitos de UI Design, hierarquia visual e consistência estética;
5. Treinar a organização de seções como produtos, seguros, diferenciais e contato;
6. Integrar design e desenvolvimento front-end em um projeto coeso e funcional;
7. Práticar o uso da ferramenta Figma na criação de layouts.
